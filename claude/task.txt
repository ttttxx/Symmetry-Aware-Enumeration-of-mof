按**对称性**（你的群论指标，非 CHGNet）将枚举构型分 High/Med/Low 三档，每档抽 `N_PER_CLASS` 个，
经「净化+预弛豫」得到干净几何后，用 CP2K(PBE-D3(BJ)) 做能量/弛豫，检验 **DFT 能量是否随对称性升高而降低**，

## 6. 各文件职责

### select_structures.py
- 按 §1 范本枚举；按 `stabilizer_size` 分 High/Med/Low（照搬 `physical_validation.py` 分桶）。
- 每档用 `RANDOM_SEED` 随机抽 `N_PER_CLASS` 个；装配 CIF（`>MAX_ATOMS` 跳过，记录原因）。
- 若 `USE_CLOSED_SHELL_VARIANT`：把 `atom_choices` 里的 `4c_Cu_1_Ch` 替换为 `4c_Cd_1_Ch` 再枚举。
- 落盘 `selected_structures.json`：`topology, coloring, stabilizer_size, gamma_size, rho, sym_class, n_atoms, init_cif`；CIF 存 `<RESULTS_DIR>/<topology>/init/`。

### sanitize.py（关键：解决 DFT 总失败）
对每个 init 结构按序：
1. `pymatgen` 把分数坐标 wrap 进胞；确认 3D 周期、晶胞合理（无零/超大真空）。
2. **元素覆盖检查**：结构中每种元素都要在 `BASIS_MOLOPT`/`GTH_POTENTIALS` 里有 `DZVP-MOLOPT-SR-GTH` 与 `GTH-PBE` 条目；缺失则该结构 `status=missing_kind` 跳过并打印缺失元素。
3. **最小非键间距**检测；`< MIN_DIST_FLOOR` → 触发预弛豫：
   - `PRECLEAN_ENGINE=="xtb"`：CP2K `RUN_TYPE GEO_OPT` + `METHOD GFN1_XTB`（快、稳），输出去碰撞几何；
   - `=="chgnet"`：`from chgnet.model import StructOptimizer; StructOptimizer().relax(struct)` 仅取几何；
   - `=="none"`：不预弛豫（仅适合本来就干净的结构）。
   预弛豫后最小间距仍 `<0.6 Å` → `status=clash_unfixable` 丢弃。
4. 干净几何存 `<topology>/clean/`，记入 json。**预弛豫只用于几何，绝不进入能量排序。**

### cp2k_runner.py
- 读 clean 几何，生成 CP2K 输入：`FORCE_EVAL` = PBE + `&VDW_POTENTIAL`/`DFTD3(BJ)`（`PARAMETER_FILE_NAME dftd3.dat`、`REFERENCE_FUNCTIONAL PBE`）、GTH 赝势、MOLOPT 基组、`&MGRID CUTOFF/REL_CUTOFF`、大胞默认 **Γ 点**。
- **鲁棒 SCF（按 `SMEARING`/`SPIN_POLARIZED` 自动选）**：
  - 闭壳层绝缘体：`&OT MINIMIZER DIIS, PRECONDITIONER FULL_SINGLE_INVERSE` + `&OUTER_SCF`；
  - 开壳层/金属性（含 Cu 等）：**关 OT，改对角化** + `&SMEAR METHOD FERMI_DIRAC ELECTRONIC_TEMPERATURE 300` + `ADDED_MOS` + `&MIXING METHOD BROYDEN_MIXING`；`UKS`+按金属数估 `MULTIPLICITY`。
  - `SCF_GUESS ATOMIC`（**首跑禁用 RESTART**）；`MAX_SCF 200` + 合理 `EPS_SCF 1e-6`。
  - 可选 `DFT_PLUS_U`：注入 `&DFT_PLUS_U`（对应金属 `L 2`）。
- 按 `RELAX_MODE` 写 `GLOBAL%RUN_TYPE`（GEO_OPT/CELL_OPT/ENERGY）与 `&MOTION`（含 `MAX_FORCE 4.5e-4`/`RMS` 等）。
- 用 `CP2K_RUN_CMD` 在各自 run 目录执行；**try/except 包裹**：不收敛/超时/崩溃 → `status=failed`，记日志，**不中断整批**；已完成的可断点续跑。
- 解析末步总能 → `dft_e_per_atom = E_total / n_atoms`；导出弛豫后结构到 `<topology>/relaxed/`。

### analyze.py
- 弛豫后用 `SpacegroupAnalyzer(symprec=SYMPREC_POSTRELAX)` 复算对称（记弛豫前后空间群变化）。
- 汇总 `dft_vs_symmetry.csv`：`topology, sym_class, rho, dft_e_per_atom, spacegroup_before/after, status`（若 `CHGNET_COMPARE` 再加 `chgnet_e_per_atom`）。
- **单拓扑内部**计算 `scipy.stats.spearmanr(rho, dft_e_per_atom)`，打印各拓扑 ρ_s 与 p 值，并标注「最低能结构所属对称档」。
- 主图：DFT 能量 vs ρ 散点（按 sym_class 着色，每拓扑一张/或子图）。
  若 `CHGNET_COMPARE`：附 CHGNet vs DFT 散点 + 对角线 + ρ_s（佐证 CHGNet 不可靠）。dpi=300，存 `RESULTS_DIR`。

### run_dft_validation.py
- import `config`，`main()` 依次 select→sanitize→run→analyze，每步打印进度与计数；
- 末尾一行总结：各拓扑 `Spearman ρ_s`、`收敛 n/N`、`丢弃/跳过 计数`、图与 CSV 路径。风格仿 `main.py` 的 `main()`。
