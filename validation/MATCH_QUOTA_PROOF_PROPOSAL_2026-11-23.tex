\subsection{Bounded output and exact-$\rho$ quotas}
\label{app:quota_proof}

We prove the coverage and prefix guarantee stated in Section~\ref{sec:enumeration}. Quota setup starts from cyclic subgroups and repeatedly takes proper pairwise joins. The cyclic subgroups generated by elements of any $S<\Gamma$ join to $S$, and all intermediate joins remain in $S$; $\Gamma$ is added separately. Within each order, tasks with identical vertex-orbit partitions are merged and the remaining partitions are searched lexicographically.
% 中文翻译：我们证明第~\ref{sec:enumeration} 节陈述的覆盖与前缀保证。配额任务构造从循环子群出发，反复取仍为真子群的两两并生成。任意 $S<\Gamma$ 中各元素生成的循环子群可并生成 $S$，且中间并生成子群均包含于 $S$；$\Gamma$ 单独加入。每个阶数内部合并顶点轨道划分相同的任务，并按字典序搜索剩余划分。

A coverage record is associated with its source search domain and acceptance rule. In ordinary enumeration, all canonical representatives in the domain are eligible; in quota mode, eligibility is restricted to $\Omega_s$ for the current target order $s$. A completed-task or completed-subtree record certifies that all eligible representatives in that region have been processed. If every completion of a later branch lies in the recorded region, rejecting that branch preserves all new eligible representatives. Quota-mode records are reused only within the same target order.
% 中文翻译：覆盖记录与其来源搜索域和接收规则对应。在普通枚举中，域内所有规范代表均符合接收条件；在配额模式中，接收条件限定为当前目标阶数 $s$ 对应的 $\Omega_s$。已完成任务或子树记录证明该区域中所有符合接收条件的代表均已处理。若后续分支的每个补全都位于该记录区域内，拒绝此分支会保留全部尚未处理且符合接收条件的代表。配额模式的记录仅在相同目标阶数内复用。

For $c^\star\in\Omega_s$, let $S=\mathrm{Stab}_{\Gamma}(c^\star)$. The task for $S$ contains $c^\star$; merging identical partitions within order $s$ preserves this domain. The minimality of $c^\star$ protects its branch from canonical prefix rejection. Coverage rejection can remove its branch only if $c^\star$ has already been processed under the same target order. Otherwise the leaf is reached and accepted by the exact-order filter. Hence the order-$s$ tasks cover $\Omega_s$ when searched to exhaustion.
% 中文翻译：对 $c^\star\in\Omega_s$，令 $S=\mathrm{Stab}_{\Gamma}(c^\star)$。$S$ 对应的任务包含 $c^\star$，在阶数 $s$ 内合并相同划分保留了此域。$c^\star$ 的最小性保证其分支不会被规范前缀拒绝。覆盖拒绝只有在相同目标阶数下已经处理过 $c^\star$ 时才可能排除其分支；否则会到达该叶，并通过精确阶数筛选。因此，阶数为 $s$ 的任务全部搜索至耗尽时覆盖 $\Omega_s$。

A task for $H$ containing a canonical representative $c^\star\in\Omega_s$ satisfies
\begin{equation}
 c^\star\in\mathrm{Fix}(H)\cap\Omega_s
 \Longrightarrow H\leq\mathrm{Stab}_{\Gamma}(c^\star)
 \Longrightarrow |H|\leq s.
\label{eq:quota_layer_order}
\end{equation}
Thus an earlier, higher-order task cannot retain a member of $\Omega_s$.
% 中文翻译：若子群 $H$ 的任务包含规范代表 $c^\star\in\Omega_s$，则 $H\leq\mathrm{Stab}_{\Gamma}(c^\star)$，从而 $|H|\leq s$。因此，此前更高阶的任务无法保留 $\Omega_s$ 的成员。

Fix the subgroup-task order, the vertex-orbit order within each task, and the label order. Let $L_s$ list the distinct representatives accepted by the order-$s$ tasks with the exact-order filter retained. This reference search uses the quota task order without quotas, timeouts, or a global cap. The coverage argument shows that $L_s$ contains every member of $\Omega_s$ exactly once. Earlier higher-order quotas cannot change this sequence: their retained records lie in other strata, and their coverage records are discarded before order $s$ is searched. Within order $s$, coverage reuse skips only eligible representatives already processed by earlier tasks or completed subtrees, preserving the order of new retained representatives.
% 中文翻译：固定子群任务顺序、各任务内的顶点轨道顺序及标签顺序。令 $L_s$ 为阶数为 $s$ 的任务在保留精确阶数筛选时接收互异代表的序列；该参考搜索沿用配额任务顺序，但关闭配额、超时和总上限。覆盖论证说明 $L_s$ 恰好列出 $\Omega_s$ 的每个成员一次。此前更高阶层的配额不会改变此序列：其已保留记录属于其他层，且其覆盖记录在阶数 $s$ 开始搜索前已清除。在阶数 $s$ 内，覆盖复用仅跳过先前任务或已完成子树已经处理的合格代表，因此保留新代表的次序不变。

Only distinct accepted representatives consume $B_s$. If no task times out and $M_{\mathrm{total}}\geq\sum_s B_s$, the returned sequence is
\begin{equation}
Y_s=\operatorname{prefix}_{\min\{B_s,|\Omega_s|\}}(L_s).
\label{eq:quota_prefix}
\end{equation}
A filled quota establishes the requested output count; layer exhaustion is established by completing all its tasks before the quota is filled.
% 中文翻译：只有被接收的互异代表才占用 $B_s$。若无任务超时且 $M_{\mathrm{total}}\geq\sum_s B_s$，返回序列为 $L_s$ 的前 $\min\{B_s,|\Omega_s|\}$ 项。配额填满说明达到了所需输出数；在配额填满之前完成该层全部任务，才能确认此层耗尽。
