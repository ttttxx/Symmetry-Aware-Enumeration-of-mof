# 截断语义、互斥任务与 CASM 启发的组合优化

## 截断语义

“只有完整搜索任务才登记整个固定点区域”为覆盖证书要求。若某任务域有 100 个代表，只取得 20 个便截断，把整个任务域标记为已处理会让后续任务跳过剩余 80 个。当前原型对截断任务不登记整域覆盖，已经记录的个别代表仍由 Trie 去重，因此不会因这项优化额外错误排除未访问区域。

- `max_total_results` 仍按新增唯一代表总数停止。
- `identity_new_limit` 仍按恒等任务新增唯一代表数停止。
- 无超时条件下，测试中两种数量上限都保持原版输出顺序和全部元数据。
- 同样秒数的 deadline 不保证返回相同集合：执行速度和覆盖约束编译开销改变了，时间截断落点也会改变。两端都仍受各自任务 deadline 检查；本轮没有重定义超时为完整覆盖。
- 精确 rho 配额实验未接入新原型，现有实验结果不受影响。未来若接入，需把“该域中哪些精确稳定子层已经完成”纳入证书；`layer_exhausted` 或 `quota_reached` 不能自动当作整个 Fix(H) 已完成。

## 能否在任务划分时消除重复

仅更换或减少子群，无法让多个非空 Fix(H) 自动互斥。例如所有位点同色的指派被所有子群固定。子群不同、轨道划分不同和固定点集合互斥是三种不同性质。

穷尽任务可以在定义阶段写成互斥区域：

`D_j = Fix(H_j) \ union(Fix(H_i), i < j)`。

但 D_j 通常不再是另一个子群的固定点集合。固定点 partition 只编码同色等式，差集会引入“至少一对不等”的条件。例如先处理 c0=c1 的任务后，后续区域需要 c0≠c1；这可以在给 c1 选值时直接排除 c0 的颜色，仍须根据 c0 的实际取值执行条件。

因此，任务定义时可以确定规则，DFS 时执行规则；两者兼容。把所有差集提前展开成无条件的小任务也能做到，但多组等式的否定是多个析取条件，展开/合取可能造成大量任务。对于截断运行，静态排除全部此前计划任务还会改变“后续任务继续覆盖此前未访问交集”的行为；当前保留只排除此前已完整覆盖的区域。

本轮没有声称实现了静态最小互斥任务划分，仍使用已完成任务的等式边界。原型的重复叶处理为 0 不意味着所有重复前缀或完整赋值形成成本均消失。

## 新增组合原型

`enumerator_casm_inspired.py` 的 `CasmInspiredMOFEnumerator` 继承上一轮交集编译器，复用原普通子群任务顺序和叶节点 Trie。它新增：

1. **整数标签**：按原字符串字典序建立整数编码；每个标签池仍保持输入顺序，保证原 DFS 顺序。时间包含编码和结果解码；返回值和 classes 中的 coloring 恢复为原标签。Trie 查询适配外部原标签。
2. **直接比较群像视图**：备用 canonical 接口按逆置换索引直接比较，首个差异确定胜负，只物化最终最小元；不为每个操作生成一个完整群像。
3. **复用比较位置**：每条 DFS 分支为每个 active 操作保存已证实相等前缀的结束位置，后续从该位置继续。赋值在祖先层保持不变，因此前面已完成的比较不必重扫。
4. **复用叶节点证书**：全部顶点赋值后，所有 active 操作都是固定该指派的非恒等操作，稳定子大小为 active 数量 + 1；该分支已通过全群 canonical 检查。因此正常 DFS 路径不再调用叶节点全群 canonical 或完整轨道计算。
5. **融合 DFS 与覆盖检查**：通过任务级 hook 使用局部递归函数，取消旧原型每层通过子类方法包装的开销；固定点边界检查和 canonical 比较处于同一搜索内。

其中整数表示、索引读取、首差异短路和减少群像分配受到 CASM 源码启发；保存 DFS 比较进度、复用 active 集合得到稳定子是对我们已有 DFS 的优化。表 2 的 CASM 接口没有 DFS，不把后两项归为 CASM 原有算法。

本轮保留 Trie 完整键去重和 Python 实现；未增加 Trie 子树耗尽剪枝、静态差集展开、子群构建缓存或 C++ 编译核心。生产 `enumerator.py`、`main.py`、精确 rho 配额子类、论文和正式结果 CSV 均未改。

## 同轮热运行时间

显式预导入 SymPy，三个版本每例各执行三次，并轮换运行位置。时间包含任务准备、搜索、保存、排序、覆盖检查和新原型的整数编码/解码；表中为中位数。

| 算例 C3/C4 | 原版 / s | 旧交集原型 / s | 组合原型 / s | 原版/组合 |
|---|---:|---:|---:|---:|
| ffc 2/2 | 0.002320 | 0.001795 | 0.001628 | 1.43× |
| ffc 3/3 | 0.008686 | 0.005617 | 0.002827 | 3.07× |
| fjh 1/2 | 0.101327 | 0.060590 | 0.044181 | 2.29× |
| fjh 2/1 | 0.197468 | 0.199952 | 0.063009 | 3.13× |
| fjh 1/3 | 2.402826 | 1.992424 | 1.123508 | 2.14× |

本轮五例中均无相对原版的性能回退；这是组合优化结果，未通过逐项消融量化各项贡献。最大例仍保留 Trie 和大量 Python 对象分配。不同轮次的 baseline 有负载/GC 波动，不直接将旧轮绝对数值与本轮作比；正式论文计时还需统一冷启动、作用群和输出工作量。
