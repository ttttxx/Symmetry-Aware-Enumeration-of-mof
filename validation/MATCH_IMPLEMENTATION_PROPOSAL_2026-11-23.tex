Python prepares the subgroup tasks and their coverage constraints. A C++ search kernel performs depth-first assignment, canonical prefix comparisons, stabilizer extraction, and complete-representative membership checks. Both the ordinary and exact-$\rho$ quota schedules use this kernel; the quota schedule supplies its target stabilizer order and remaining layer budget. Records are returned in batches and decoded and sorted in Python.
