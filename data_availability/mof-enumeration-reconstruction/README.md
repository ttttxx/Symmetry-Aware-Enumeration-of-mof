# MOF Enumeration and Reconstruction Data Package

This package supports the manuscript:

`Symmetry-Constrained Enumeration and Oriented Construction of Ordered MOF Candidates`

The files make representative reconstructed models and the structural audit inspectable. All CIFs in this package are pre-relaxation starting models generated by rigid-body reconstruction.

## Field Definitions

- `PLD` / `LCD`: pore-limiting diameter (Df) / largest cavity diameter (Di), in Å. The two descriptor fields were corrected against all 30 original Zeo++ outputs on 2026-11-10; see `tables/zeopp_descriptor_correction_20261110.md`. GCMC metrics and candidate membership were retained.

- `sanitizable CIF`: the reconstructed CIF was written, passed deterministic cleanup, and could be reloaded by the validation workflow.
- `topology-pass`: after sanitization, the recovered quotient-graph skeleton matched the intended topology-level target used by the audit.
- `clash-free`: the current pre-relaxation short-contact validator did not report steric-clash flags for the assembled starting model.
- `rho`: the normalized stabilizer size, defined as `rho(c) = |Stab(c)| / |Gamma|`, where `Gamma` is the proper-rotation group used for enumeration.
- `pre-relaxation starting model`: a rigidly assembled periodic candidate model that can be inspected or passed to later relaxation, DFT, GCMC, or active-learning workflows. It is not a final relaxed material.
- `APS`: the derived adsorbent performance score used in the CO2/N2 ordering check, computed in this extract as selectivity times CO2 working capacity, following the manuscript definition. Regenerability is reported separately.

## Current Structural Audit

The current manuscript audit reconstructs all 42 symmetry-distinct `ffc` assignments and 30 of 394 `fjh` assignments. The `fjh` sample contains 10 assignments from each stabilizer-based High, Med, and Low stratum. The exact seed and selected IDs are listed in `tables/reconstruction_audit_protocol_seeded_2026-10-10.json`. Assembly, CIF sanitization and reload, topology recovery, short-contact screening, and connection-site closure are recorded for every audited structure. This audit uses geometric and structural checks; it does not run DFT.

The earlier 27-structure audit files remain available in their original paths for provenance. The manuscript's current audit totals are in the files with the `seeded_2026-10-10` suffix.

The CO2/N2 ordering-check table includes 30 candidates across nine composition–`rho` cells, with three or four candidates per cell. Each candidate was evaluated in five independent GCMC runs; direct metrics are reported as their arithmetic means, with run-to-run standard deviations in the candidate-level table. APS follows the manuscript definition and is calculated from mean selectivity times mean CO2 working capacity; regenerability remains separate. The first run was reparsed from its original RASPA output using `Average loading absolute [mol/kg framework]`, correcting the unit mismatch in the earlier labels; this is numerically equivalent to mmol/g. Zeo++ descriptors for nine additional candidates used a 1.86 Å probe and 50,000 samples; selection details are in the adjacent protocol JSON. These screening labels are calculated on as-assembled starting models.

The current bounded `vba` measurements compare equal per-layer quotas with current C++ DFS prefixes stopped at the same total output count. Both use the common lexical node pools. Layer medians exclude initial subgroup setup. Earlier dated records remain archived for provenance.

The current CASM comparison records use the same Gamma and output fields on both sides, with separate full-factor-group counts and measured run metadata. They are stored with the current implementation snapshot in `reproducibility/unified_20261123/`. The DFT source table includes all 21 converged \texttt{ffc} and 32 converged \texttt{fjh} single-point calculations, the absolute energies, and $\Delta E$ relative to the minimum within each topology/composition group. Each row links to the corresponding cleaned input CIF. CP2K raw output logs are not included.

The X-site fusion files document the fixed-geometry cutoff scans and the full reconstruction/CIF checks at 0.8 and 1.2 \AA. The protocol note identifies the sampled model set and explains the scope of each table.

## Current enumeration source of truth (2026-11-23)

The current main and supplementary enumeration tables use `reproducibility/unified_20261123/`, with the ABI-4 implementation and one common lexicographic template-pool definition. The older CASM and vba CSV files listed above are dated provenance; their timings are not used in the current manuscript.
