# 业务理解

- 软件名称：金属有机框架（MOF）对称性感知结构枚举与可视化系统V1.0
- 产品定位：面向材料科学研究人员的金属有机框架（MOF）三维结构交互式可视化与数据管理系统。用户通过Web浏览器配置拓扑骨架和分子构件参数，系统自动计算并生成候选MOF晶体结构，在页面上以交互式3D模型直观呈现分子空间排布，支持多种渲染样式切换、结构属性浏览和数据导出，使研究者无需安装专业软件即可快速查看、筛选和下载MOF候选结构。
- 面向领域 / 行业：计算材料科学 / 化学信息学 — 金属有机框架（MOF）材料的计算设计与结构预测领域
- 核心价值：为MOF材料研究人员提供一个基于浏览器的「所见即所得」三维结构可视化工作台。用户通过左侧参数面板选择拓扑和构件后，系统在后台完成结构计算，将结果以交互式3D分子模型、统计指标卡片和汇总数据表三种形式在页面上直接呈现。用户可在浏览器中旋转、缩放、切换渲染样式查看每个候选结构的空间形态，逐结构下载CIF晶体学文件，或导出完整JSON数据进行后续分析。整个操作流程在同一页面内完成，无需在命令行、脚本和专业可视化软件之间来回切换。
- 证据文件：`业务理解证据.md`

## 目标用户

- 从事MOF材料计算设计的高校和科研院所研究人员（化学、材料科学、化工等专业）
- 从事新型多孔材料筛选与性质预测的计算化学研究人员
- 需要批量生成候选MOF结构进行高通量筛选的材料基因组研究人员

## 主要业务功能

- 交互式3D分子结构可视化与多样式渲染
- 枚举结果的统计汇总与数据导出
- MOF拓扑选择与配体参数配置
- 结构枚举运行与实时进度反馈
- 结构汇总表格浏览与排序筛选
- CIF晶体结构文件与JSON数据下载

## 功能说明

- 交互式3D分子结构可视化与多样式渲染：系统在浏览器页面中嵌入py3Dmol.js三维分子浏览器，将计算生成的MOF晶体结构以交互式3D模型直接呈现。用户可用鼠标拖拽旋转结构、滚动滚轮缩放、右键平移视角，从任意角度观察晶胞内的原子空间排布和孔道形态。提供四种渲染样式供切换：球棍模型（Ball and Stick）兼顾原子位置和键连关系、棍模型（Stick）突出拓扑骨架、球模型（Sphere）便于观察孔道大小、线框模型（Line）展示最简结构轮廓。排名靠前的结构以最多三列网格布局并列展示，每个结构标注排名和稳定子大小，方便横向比较不同候选结构的空间形态差异。
- 枚举结果的统计汇总与数据导出：枚举完成后，页面自动展示四项核心统计指标——拓扑名称、自同构群大小、有效结构总数和实际生成的CIF文件数——以醒目的大号数字卡片并排呈现。下方列出所有有效结构的汇总表格，含结构编号、着色方案（各节点分配的配体分子）、稳定子大小和轨道大小四列，支持列标题点击排序和垂直滚动浏览。用户可逐结构下载CIF文件，也可一键导出包含全部枚举细节的完整JSON数据文件，用于后续的量化计算或数据分析。
- MOF拓扑选择与配体参数配置：用户在浏览器左侧参数面板中，通过下拉菜单从系统内置的20余种MOF拓扑类型中选择目标骨架。选择后系统自动解析该拓扑的节点度分布，并按度数分组动态生成配体多选菜单，每个度数槽位列出nodes/库中该配位数的全部可用配体分子。系统智能默认预选含Cu的配体（如4c_Cu_1_Ch），用户可按需勾选或切换其他配体。同时通过边缘分子下拉菜单选择连接分子类型，通过滑块和数字输入框分别设置生成CIF数量和枚举搜索上限。
- 结构枚举运行与实时进度反馈：用户点击「Generate Structures」按钮后，系统在页面中央显示蓝色进度提示条，告知计算正在运行中。后台按序执行拓扑数据加载、对称性分析、结构枚举、自验证和CIF组装等步骤。运行成功时蓝色提示条变为绿色，显示生成的CIF数量和有效结构总数；运行异常时变为红色，展示具体错误信息和Python异常堆栈。用户可展开运行日志折叠区域，查看各步骤的详细终端输出以辅助问题诊断。
- 结构汇总表格浏览与排序筛选：在3D视图区域下方，系统以交互式数据表格列出全部有效枚举结构。每条结构记录包含编号、着色方案、稳定子大小和轨道大小。表格高度固定为300像素，数据行数较多时支持垂直滚动。用户可点击列标题切换排序依据，例如按轨道大小升序查找小轨道结构，或在表格中定位特定排名编号对应的结构行，对照上方的3D视图进行核查。
- CIF晶体结构文件与JSON数据下载：系统提供两种层级的数据导出：单个结构的CIF文件下载和全部结果的JSON文件下载。每个3D视图面板下方设有独立下载按钮，文件名自动包含拓扑名、配体组合、排名和稳定子大小信息。页面底部提供完整JSON结果预览（默认展示前20条结构）和下载按钮，JSON数据包含meta（拓扑、群大小、验证统计）和structures（全部枚举结构详情）两大模块，下载文件名含时间戳便于归档。

## 操作手册页面/流程模块

1. 主界面概览与参数配置：在浏览器中打开本系统的Streamlit Web地址后默认进入此页面。
   - 使用场景：研究者在确定了感兴趣的MOF拓扑骨架后，进入此页面配置该拓扑所需的节点配体和连接分子，并根据需要的候选结构数量调整枚举参数。配置完成后点击生成按钮启动计算。
   - 操作要点：用户在左侧边栏的拓扑下拉菜单中选择目标拓扑类型（如ffc、vba等）。选择后，系统自动读取该拓扑的图数据，分析出节点度分布（例如需要4个3-c节点和3个4-c节点），并在下拉框下方显示需求提示；用户在各度数槽位的多选菜单中勾选或取消配体选项。系统默认选中含Cu的配体作为初始值。如果某度数没有可用配体，系统会在该槽位显示警告提示；用户在边缘分子下拉菜单中选择用作连接分子的CIF（如1B_4H_Ch）；用户拖动Top-K滑块设置需要生成CIF文件的高对称结构数量，在最大枚举结果输入框中设置枚举搜索上限
2. 枚举运行与进度反馈：在主界面参数配置完成后，点击「Generate Structures」按钮自动进入此流程。
   - 使用场景：研究者配置好参数并点击生成按钮后，系统自动进入计算阶段，执行拓扑数据加载、对称性分析、结构枚举、自验证和CIF组装流程。用户等待几分钟后查看结果。
   - 操作要点：用户点击按钮后等待系统自动执行计算，无需手动干预；计算过程中可观察页面上的状态提示颜色变化（蓝色=运行中，绿色=成功，红色=失败）；如遇错误，用户可展开「Run log」区域查看终端输出日志，了解失败的具体步骤和原因；如遇文件不存在（FileNotFoundError），根据错误提示检查对应拓扑的图数据文件是否已通过预处理生成
3. 结果统计指标查看：枚举成功完成后自动显示在页面上，位于进度提示和3D视图之间。
   - 使用场景：研究者在枚举完成后，首先关注统计指标卡片以确认枚举结果是否符合预期——有效结构数量是否在合理范围、对称群大小是否反映拓扑的对称性水平、生成的CIF文件数是否与Top-K设置一致。
   - 操作要点：枚举完成后，用户直接向下滚动页面查看四列指标卡片；点击「Verification stats」展开区域查看Burnside引理验证的详细数值；如果有效结构数远小于最大枚举结果数，说明搜索空间内所有不等价结构已被穷举；如果有效结构数等于设置的最大枚举结果数，说明可能还有更多结构未被搜索到，用户可适当增大max_results参数后重新运行
4. 3D分子结构交互式查看：枚举成功完成后，Viewer区域自动出现在统计指标卡片下方。
   - 使用场景：研究者在得到枚举结果后，通过3D视图直观检查排名靠前的MOF结构的空间排布、孔道形态和节点连接方式，判断结构是否合理、是否值得进行后续的DFT计算或性质预测。可通过切换渲染样式来突出拓扑骨架（棍模型）或观察孔道大小（球模型）。
   - 操作要点：用户先在渲染样式下拉框中选择偏好的显示方式，选择后所有3D视图自动刷新渲染效果；用户用鼠标在任意3D视窗中拖拽旋转结构，滚轮缩放，右键平移，从不同角度观察晶胞内的原子排布；用户可对比同排不同排名结构的空间形态差异——一般排名越小（Rank 0）的结构对称性最高，稳定性通常也更好；用户对感兴趣的结构，点击其下方的Download按钮将CIF文件下载到本地，用于后续计算
5. 结构汇总表格浏览：位于3D Viewer区域下方的「All Valid Structures」子标题区域。
   - 使用场景：研究者查看完高排名结构的3D视图后，向下浏览汇总表格以了解全部枚举结果的分布——哪些着色方案的稳定子最大（对称性最高）、轨道大小是否合理，进而判断是否需要对某些中低排名的结构也进行3D检查和下载。
   - 操作要点：用户向下滚动页面到表格区域；用户通过表格的列标题排序功能（点击列名）可改变排序依据，例如按Orbit Size升序排列查看小轨道结构；用户浏览各结构的着色方案列，了解不同配体分配模式对应的稳定子大小差异；对照3D视图中的排名编号，用户可在表格中找到对应结构行查看详细属性
6. JSON结果预览与数据导出：位于汇总表格下方的「Full JSON Output」区域。
   - 使用场景：研究者需要将枚举结果导入到自有的数据分析流程（如Python脚本、Jupyter Notebook）中进一步处理，或需要归档本次运行的完整输出时，使用此功能预览数据格式并导出。
   - 操作要点：用户点击「Preview JSON (first 20 structures)」展开折叠区域，查看JSON数据的顶层结构（meta和structures字段）以及前20条结构的详细内容；用户确认数据格式符合需求后，点击「Download Complete JSON」按钮，浏览器触发JSON文件下载；下载的文件名包含拓扑名、配体组合和时间戳信息，便于归档管理

- 软件的主要功能：1. 基于Streamlit框架的浏览器端参数配置界面，包含拓扑类型下拉选择、按度数分组的配体多选菜单、边缘分子选择、结构生成数量滑块和枚举搜索上限输入；2. 运行状态实时反馈，以颜色编码（蓝/绿/红）提示计算进度和结果，支持展开查看详细运行日志；3. 基于py3Dmol.js的交互式3D分子结构浏览器，支持旋转、缩放、平移操作和四种渲染样式（球棍/棍/球/线框）实时切换，Top-K结构以网格布局并列展示；4. 四项核心统计指标卡片（拓扑名称、对称群大小、有效结构数、CIF生成数）和Burnside引理验证详情展示；5. 全部有效结构的交互式汇总表格，含着色方案、稳定子大小、轨道大小列，支持列排序和滚动浏览；6.
