项目核心模块 核心算法层 - SymmetryEngine (symmetry.py) — 基于 pymatgen SpacegroupAnalyzer 计算拓扑图的自同构群（automorphism group），包含 lattice 转置、元素清洗（Zn/C 替换）、多精度回退、镜像过滤等容错策略。 - MOFEnumerator (enumerator.py) — 实现子群格下降（Subgroup Lattice Descent）DFS 算法，对每组轨道（orbit）尝试所有配体颜色分配，通过度数计数约束和正则对称性剪枝进行早期切割；使用 Trie 去重 + 大顶堆维护 Top-K 结果。 - BridgeVerifier (verification.py) — 使用 Burnside Lemma 进行算法自验证：Sum(1/ Stab(s) ) 应等于 Fix(e) / G ，分"固定组分"和"所有组分"两类计算理论右侧值。 - StructureAssembler (assembler.py) — 将枚举的着色方案转换为 3D 晶体结构（CIF），包含晶格自适应缩放、拓扑展开（alpha matrix/Bstar）、X 原子融合、空间群恢复、CIF 后处理（1-indexed 标签、 geom bond 表）。 - StructureValidator (structure validator.py) — 三层硬性校验：碰撞检测（vdW 半径比）、拓扑还原校验（图同构）、对称性守恒校验（空间群偏离 P1 判定）。 - enrich graph data with topology (main.py) — 使用真实的晶格平移 sym 向量计算 BFS 路径构建环基（cycle basis），生成 Bstar 和 alpha matrix 矩阵，通杀扭曲或多重边 MOF。 - run enumeration (main.py) — 管线的参数化入口，串联对称性分析 → 枚举 → 验证 → 组装全流程。 - Edge / Node (external lib/) —

Example: 0x414570a4 represents 12.340000152587890625 c. expected output: floating point output for the corresponding input in hex. This should be computed using a high(er) precision library and then rounded to same format as the input. d. ulperror: expected maximum ulp error of the function.
