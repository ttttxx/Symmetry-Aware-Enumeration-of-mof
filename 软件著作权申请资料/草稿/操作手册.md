## 二、说明

金属有机框架（MOF）对称性感知结构枚举与可视化系统V1.0是一套面向材料科学研究人员的Web端三维结构可视化工具，适用于MOF材料的计算设计与结构筛选场景。用户进入系统后，可在左侧面板配置拓扑和构件参数，点击按钮触发结构计算，在同一页面中查看交互式3D模型、浏览统计指标和数据表格，并下载CIF文件和JSON结果。

日常使用时，从事 MOF 材料计算设计的高校和科研院所研究人员（化学、材料科学、化工等专业）、从事新型多孔材料筛选与性质预测的计算化学研究人员、需要批量生成候选 MOF 结构进行高通量筛选的材料基因组研究人员可以按照页面提示从入口进入相应页面，查看当前业务状态，并根据页面中的按钮、输入框、列表或弹窗继续处理。为 MOF 材料研究人员提供一个基于浏览器的「所见即所得」三维结构可视化工作台。用户通过左侧参数面板选择拓扑和构件后，系统在后台完成结构计算，将结果以交互式3D分子模型、统计指标卡片和汇总数据表三种形式在页面上直接呈现。用户可在浏览器中旋转、缩放、切换渲染样式查看每个候选结构的空间形态，逐结构下载 CIF 晶体学文件，或导出完整 JSON 数据进行后续分析。整个操作流程在同一页面内完成，无需在命令行、脚本和专业可视化软件之间来回切换。

金属有机框架（MOF）对称性感知结构枚举与可视化系统是一套面向材料科学研究人员的 Web 端三维结构可视化与数据管理工具。用户通过浏览器打开系统后，在左侧参数面板中选择目标 MOF 的拓扑骨架、节点配体分子和边缘连接分子，设置生成数量等参数，点击按钮即可触发结构计算。计算完成后，系统在同一页面内以交互式3D分子模型、统计指标卡片和汇总数据表三种形式展示结果，用户可旋转缩放查看每个候选结构的空间形态、切换渲染样式、按列排序浏览全部结构属性，并逐结构下载 CIF 晶体学文件或导出完整 JSON 数据。整个操作在浏览器中在同一页面中完成，无需安装任何专业分子可视化软件。

系统的3D可视化模块基于 py3Dmol.js 构建，将生成的 CIF 结构以白色背景的三维分子模型嵌入页面。用户可用鼠标自由旋转结构观察原子空间排布、滚轮缩放查看局部细节、右键平移调整视角中心。系统提供球棍模型（同步展示原子球体和键连棍）、棍模型（仅显示键连骨架）、球模型（仅显示原子球体，适合评估孔道尺寸）和线框模型（最简线条轮廓）四种渲染样式，通过页面上的下拉菜单一键切换即可同步刷新所有视窗。排名靠前的高对称性结构以多列网格并排展示，每个视窗标注排名编号和稳定子大小，方便横向对比。

本手册用于说明软件的用途、功能特点、运行要求和页面操作流程。各功能章节按用户能够看到的页面、入口、按钮、输入项、提示信息和处理结果进行说明。

## 三、功能特点

用户可在主界面概览与参数配置页面用户进入系统的首个页面，用于了解系统功能、选择目标拓扑类型、配置各度数节点的配体分子、选择边缘连接分子和设置枚举参数，是所有后续操作的起点。页面上的页面顶部居中显示系统标题「MOF Structure Enumerator」和功能简述文字、左侧边栏标题「Parameters」，下方依次排列：、拓扑类型下拉选择框「Topology (DATA_PREFIX)」，列出系统支持的所有拓扑名称、拓扑需求自动分析提示文字，显示当前拓扑需要的各度数节点数量和按度数分组的配体多选菜单，每个度数槽位一个独立的多选下拉框，自动预选含 Cu 的配体会集中呈现当前可操作内容，用户处理完成后可以看到选择拓扑后，下拉框下方立即显示该拓扑的需求分析文字，例如「Current topology requires: 4 × 3-c nodes, 3 × 4-c nodes」、点击生成按钮后，页面显示蓝色进度提示「Running enumeration — this may take a few minutes...」和运行成功完成后，进度提示变为绿色成功信息，显示生成的 CIF 数量和有效结构总数。

在枚举运行与进度反馈页面中，用户主要处理用户点击生成按钮后，系统在后台执行完整的四步计算管线，同时界面实时显示运行状态。用户可在此阶段了解计算进度和中间输出。系统把页面中央显示蓝色信息条「Running enumeration — this may take a few minutes...」、成功完成后蓝色条变为绿色成功提示、失败时蓝色条变为红色错误提示，下方显示错误详情和异常堆栈和运行日志可展开区域（Run log expander），默认折叠放在当前操作区域，处理结束后会反馈成功：绿色条显示「Done! Generated N CIF file(s). (M valid structures total)」、文件缺失：红色条显示具体的文件路径错误信息和其他异常：红色条显示「Enumeration failed — see traceback below.」并附带Python traceback。

结果统计指标查看页面关注的是枚举完成后，用户可以一目了然地查看本次运行的核心统计指标，包括所选拓扑、对称群大小、枚举出的有效结构数和实际生成的 CIF 文件数，快速评估枚举结果的规模和质量。用户通过四列等宽排列的指标卡片：Topology（拓扑名称）、Group Size |G|（自同构群大小）、Valid Structures（有效结构数）、CIFs Generated（生成 CIF 数）和可展开的「Verification stats」折叠区域，内含 Burnside 引理验证的 JSON 详细数据（LHS构造值、RHS理论值、差异值、验证通过与否）确认当前状态，并在操作结束后获得指标卡片以白色背景+大号数字突出显示，数值变化时卡片内容刷新和验证数据以 JSON 格式在展开区域内显示，包含 verified 布尔字段直接表明验证结果。

用户可在3D分子结构交互式查看页面用户可以在浏览器中直接以交互式3D方式查看生成的高对称性 MOF 晶体结构，支持旋转、缩放、平移和多种渲染样式切换，无需安装任何分子可视化软件即可直观检查结构质量。每个结构旁附有排名编号、稳定子大小和 CIF 文件下载按钮。页面上的渲染样式下拉选择框「Select 3D Rendering Style」，含四种选项：Ball and Stick（球棍模型）、Stick（棍模型）、Sphere（球模型）、Line（线框模型），默认Ball and Stick、最多3列网格布局的3D分子视图面板，每个面板包含：、排名和稳定子大小标注（如「Rank 0 | Stabilizer = 12」）、嵌入的 py3Dmol 交互式3D视窗（白色背景），可通过鼠标拖拽旋转、滚轮缩放、右键平移和每个结构下方的「Download <文件名>.cif」下载按钮会集中呈现当前可操作内容，用户处理完成后可以看到切换渲染样式后所有3D视图立即重绘、每个视窗自动居中并适应窗口大小和下载按钮点击后浏览器触发文件下载，文件名包含拓扑名、配体组合、排名和稳定子大小信息。

在结构汇总表格浏览页面中，用户主要处理用户以表格形式浏览所有有效枚举结构的关键属性，包括结构编号、着色方案（各节点分配的配体分子）、稳定子大小和轨道大小，便于快速比较和筛选感兴趣的结构。系统把子标题「All Valid Structures」、一个可滚动（高度300px）的交互式数据表格，列包括：id（结构编号）、Coloring（着色方案，格式为「配体A | 配体B | ...」）、Stabilizer Size（稳定子大小）、Orbit Size（轨道大小）和表格按稳定子大小降序排列（枚举结果默认排序）放在当前操作区域，处理结束后会反馈表格使用 Streamlit 的use_container_width模式自适应页面宽度和数据量较大时表格支持垂直滚动，默认显示高度300像素。

JSON结果预览与数据导出页面关注的是用户可预览枚举结果的完整 JSON 数据格式，并下载包含所有元信息（拓扑、群大小、验证统计）和全部结构详情的完整 JSON 文件，用于后续的数据分析、绘图或集成到其他材料信息学工具中。用户通过子标题「Full JSON Output」、可展开的「Preview JSON (first 20 structures)」折叠区域，内含前20条结构的 JSON 格式预览（缩进展示）和蓝色「Download Complete JSON」下载按钮（type=primary 主按钮样式）确认当前状态，并在操作结束后获得展开折叠区域后，JSON以缩进格式彩色渲染显示和下载文件名格式为<拓扑名>_<配体组合>_<时间戳>.json，自动保存在浏览器的默认下载目录。

## 五、主界面概览与参数配置

用户可在主界面概览与参数配置页面用户进入系统的首个页面，用于了解系统功能、选择目标拓扑类型、配置各度数节点的配体分子、选择边缘连接分子和设置枚举参数，是所有后续操作的起点。用户可以通过在浏览器中打开本系统的Streamlit Web地址后默认进入此页面。

研究者在确定了感兴趣的 MOF 拓扑骨架后，进入此页面配置该拓扑所需的节点配体和连接分子，并根据需要的候选结构数量调整枚举参数。配置完成后点击生成按钮启动计算。

用户在主界面概览与参数配置页面会看到页面顶部居中显示系统标题「MOF Structure Enumerator」和功能简述文字、左侧边栏标题「Parameters」，下方依次排列：、拓扑类型下拉选择框「Topology (DATA_PREFIX)」，列出系统支持的所有拓扑名称、拓扑需求自动分析提示文字，显示当前拓扑需要的各度数节点数量、按度数分组的配体多选菜单，每个度数槽位一个独立的多选下拉框，自动预选含 Cu 的配体、边缘分子下拉选择框「Forced Edge (FORCED_EDGE)」、分隔线后的Top-K CIF数量滑块（范围1-10，默认5）和最大枚举结果数字输入框（范围100-100,000，默认10,000）等信息，并可依据页面显示继续处理。

使用该功能时，用户先用户在左侧边栏的拓扑下拉菜单中选择目标拓扑类型（如ffc、vba等）。选择后，系统自动读取该拓扑的图数据，分析出节点度分布（例如需要4个3-c节点和3个4-c节点），并在下拉框下方显示需求提示，随后用户在各度数槽位的多选菜单中勾选或取消配体选项。系统默认选中含 Cu 的配体作为初始值。如果某度数没有可用配体，系统会在该槽位显示警告提示，接着用户在边缘分子下拉菜单中选择用作连接分子的CIF（如1B_4H_Ch），之后用户拖动 Top-K 滑块设置需要生成 CIF 文件的高对称结构数量，在最大枚举结果输入框中设置枚举搜索上限，最后确认所有参数后，用户点击「Generate Structures」按钮启动计算。

页面会按照每个度数槽位必须至少选择一个配体，否则点击生成按钮时页面报错「Please select at least one ligand for each degree slot.」并停止执行、拓扑图 JSON 文件必须存在于data/<拓扑名>/目录下，否则枚举会因 FileNotFoundError 异常而终止并在页面上显示错误信息和配体库和边缘库的 CIF 文件必须存在于nodes/和edges/目录下等规则限制或提示用户。处理结束后，用户可以看到选择拓扑后，下拉框下方立即显示该拓扑的需求分析文字，例如「Current topology requires: 4 × 3-c nodes, 3 × 4-c nodes」、点击生成按钮后，页面显示蓝色进度提示「Running enumeration — this may take a few minutes...」、运行成功完成后，进度提示变为绿色成功信息，显示生成的 CIF 数量和有效结构总数和运行异常时，进度区域显示红色错误信息和 Python 异常堆栈，部分运行日志可在展开区域查看。

## 六、枚举运行与进度反馈

用户可在枚举运行与进度反馈页面用户点击生成按钮后，系统在后台执行完整的四步计算管线，同时界面实时显示运行状态。用户可在此阶段了解计算进度和中间输出。用户可以通过在主界面参数配置完成后，点击「Generate Structures」按钮自动进入此流程。

研究者配置好参数并点击生成按钮后，系统自动进入计算阶段，执行拓扑数据加载、对称性分析、结构枚举、自验证和 CIF 组装流程。用户等待几分钟后查看结果。

该部分提供页面中央显示蓝色信息条「Running enumeration — this may take a few minutes...」、成功完成后蓝色条变为绿色成功提示、失败时蓝色条变为红色错误提示，下方显示错误详情和异常堆栈和运行日志可展开区域（Run log expander），默认折叠等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先用户点击按钮后等待系统自动执行计算，无需手动干预，随后计算过程中可观察页面上的状态提示颜色变化（蓝色=运行中，绿色=成功，红色=失败），接着如遇错误，用户可展开「Run log」区域查看终端输出日志，了解失败的具体步骤和原因，最后如遇文件不存在（FileNotFoundError），根据错误提示检查对应拓扑的图数据文件是否已通过预处理生成。

如果不满足计算过程中如果拓扑图文件缺失，系统抛出 FileNotFoundError 并显示具体缺失路径、任何步骤的异常都会被捕获并以红色错误信息展示在界面上和部分运行日志在异常情况下也可通过展开区域查看，帮助诊断问题等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括成功：绿色条显示「Done! Generated N CIF file(s). (M valid structures total)」、文件缺失：红色条显示具体的文件路径错误信息和其他异常：红色条显示「Enumeration failed — see traceback below.」并附带Python traceback。

## 七、结果统计指标查看

用户可在结果统计指标查看页面枚举完成后，用户可以一目了然地查看本次运行的核心统计指标，包括所选拓扑、对称群大小、枚举出的有效结构数和实际生成的 CIF 文件数，快速评估枚举结果的规模和质量。用户可以通过枚举成功完成后自动显示在页面上，位于进度提示和3D视图之间。

研究者在枚举完成后，首先关注统计指标卡片以确认枚举结果是否符合预期——有效结构数量是否在合理范围、对称群大小是否反映拓扑的对称性水平、生成的 CIF 文件数是否与 Top-K 设置一致。

页面上主要呈现四列等宽排列的指标卡片：Topology（拓扑名称）、Group Size |G|（自同构群大小）、Valid Structures（有效结构数）、CIFs Generated（生成 CIF 数）和可展开的「Verification stats」折叠区域，内含 Burnside 引理验证的 JSON 详细数据（LHS构造值、RHS理论值、差异值、验证通过与否）等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先枚举完成后，用户直接向下滚动页面查看四列指标卡片，随后点击「Verification stats」展开区域查看 Burnside 引理验证的详细数值，接着如果有效结构数远小于最大枚举结果数，说明搜索空间内所有不等价结构已被穷举，最后如果有效结构数等于设置的最大枚举结果数，说明可能还有更多结构未被搜索到，用户可适当增大max_results参数后重新运行。

用户可在3D分子结构交互式查看页面用户可以在浏览器中直接以交互式3D方式查看生成的高对称性 MOF 晶体结构，支持旋转、缩放、平移和多种渲染样式切换，无需安装任何分子可视化软件即可直观检查结构质量。每个结构旁附有排名编号、稳定子大小和 CIF 文件下载按钮。用户可以通过枚举成功完成后，Viewer区域自动出现在统计指标卡片下方。

研究者在得到枚举结果后，通过3D视图直观检查排名靠前的 MOF 结构的空间排布、孔道形态和节点连接方式，判断结构是否合理、是否值得进行后续的 DFT 计算或性质预测。可通过切换渲染样式来突出拓扑骨架（棍模型）或观察孔道大小（球模型）。

## 十一、典型使用流程

用户完成一次完整业务时，通常先进入金属有机框架（MOF）对称性感知结构枚举与可视化系统V1.0，再选择或创建业务对象，随后按照页面提示处理内容并查看结果。

用户完成一次完整的 MOF 结构筛选通常按以下流程操作：

第一步，在浏览器中打开本系统的 Web 应用。页面加载后左侧为参数配置面板，右侧主区域显示系统标题和功能简述文字，运行前右侧为空白区域。

第二步，在左侧面板依次选择目标拓扑类型（如 ffc、vba 等），系统自动解析该拓扑的节点度分布需求并在下拉框下方显示提示。然后按度数分组勾选配体分子（系统已默认预选含 Cu 配体），再选择边缘连接分子类型，最后拖动滑块设置需要生成的 CIF 结构数量和数字输入框设置枚举搜索上限。

第三步，点击「Generate Structures」按钮触发计算。页面中央出现蓝色进度提示条，系统在后台自动完成结构计算。运行过程中用户可观察界面状态提示的颜色变化（蓝色表示正在运行，绿色表示成功完成，红色表示出现异常）。

第四步，计算完成后，页面顶部显示四项核心统计指标卡片，分别列出当前拓扑名称、自同构群大小、枚举出的有效结构总数和实际生成的 CIF 文件数。用户可展开验证详情折叠区域查看验证数据。

第五步，向下滚动到 3D 视图区域，在渲染样式下拉菜单中选择显示方式后，用鼠标旋转、缩放、平移查看每个候选结构的三维空间形态，横向对比不同排名结构的孔道和骨架差异。

第六步，继续向下浏览全部有效结构的汇总表格，通过列标题排序定位感兴趣的结构行，对照上方 3D 视图确认结构质量。

第七步，对满意的结构点击其下方的 Download 按钮下载 CIF 文件，或在页面底部展开 JSON 预览后点击下载按钮导出完整结果数据。



## 十二、常见问题解答

问题：点击「Generate Structures」后报错「Graph file not found」，怎么处理？
解决方法：这个错误表示所选拓扑的图数据文件尚未通过预处理生成。您需要先运行预处理脚本，将目标 MOF 的 CIF 文件放入data/<拓扑名>/目录，然后执行python utils/parse_cif.py data/<拓扑名>/<文件>.cif生成对应的_graph.json拓扑图文件，之后即可正常使用。

问题：为什么某个度数的配体多选菜单为空或显示警告？
解决方法：多选菜单的选项来自nodes/目录下的 CIF 文件。如果某度数（如5-c）没有配体 CIF 文件，系统会显示「No N-c ligands available in library!」警告。此时您需要先将对应配位数的配体分子 CIF 文件放入nodes/目录中，刷新页面后即可在菜单中看到新选项。

问题：枚举结果中的Valid Structures数量很大（接近max_results），是否还有更多结构没有被找到？
解决方法：有可能。当有效结构数等于或非常接近您设置的max_results值时，说明搜索容量可能已被用完，可能还有更多结构尚未被发现。建议您适当增大max_results参数的值并重新运行。另外您也可以查看「Verification stats」区域中的 verified 字段——如果为 true 则表明 Burnside 引理验证通过，枚举结果是完整的；如果为 false 则存在遗漏。

问题：为什么有些拓扑生成了0个 CIF 文件（CIFs Generated = 0）？
解决方法：当所有 Top-K 结构的组装过程都因shape mismatch（配体分子与拓扑边的几何形状不匹配）而失败时，CIF生成数为0。这通常发生在所选配体的连接点方向与拓扑边的方向差异过大、无法将配体合理嵌入晶格位置的情况。建议尝试更换边缘连接分子类型，或选择几何形状更为匹配的配体文件。

问题：3D视图中分子结构显示不全或位置偏移怎么办？
解决方法：3D视图使用 py3Dmol 进行渲染，首次加载时会自动居中并缩放至适应窗口。如果结构显示不完整，可以尝试用鼠标滚轮缩小视图，或右键拖拽平移画面。如果某个结构持续显示异常，可以将该 CIF 文件下载到本地后用其他分子可视化软件（如VESTA、Mercury）打开确认结构本身是否正常。

问题：如何批量运行多个拓扑或配体组合？
解决方法：Web界面每次运行处理一个拓扑-配体组合。如需批量运行，建议直接使用 Python 命令行调用 main.py 或编写脚本循环调用run_enumeration函数。枚举结果 JSON 文件保存在results/目录下，文件名包含拓扑和配体信息便于区分。

## 十三、术语表

| 术语 | 解释 |
| --- | --- |
| MOF（金属有机框架） | Metal-Organic Framework，由金属离子或金属簇（节点）与有机配体（连接分子）通过配位键自组装形成的多孔晶体材料，具有超高比表面积和可调控的孔道结构，广泛应用于气体吸附、分离、催化等领域。 |
| 拓扑（Topology） | 在本系统中指 MOF 框架的网络连接方式，描述了金属节点与有机配体之间的连接模式。常见 MOF 拓扑类型包括ffc、vba、sod、pcu等，每种拓扑有不同的节点度数分布。 |
| 配体（Ligand / Node） | 在本系统中指 MOF 结构中的金属节点或有机节点分子，每个节点有特定的配位数（连接度），如4c表示该节点有4个连接点与相邻分子成键。 |
| 自同构群（Automorphism Group） | 由拓扑图中保持节点连接关系不变的所有节点置换操作构成的数学群。群的大小（|G|）反映了拓扑的对称性高低——群越大，对称性越高。 |
| 轨道（Orbit） | 在群作用下，拓扑图中的节点被划分为若干轨道，同一轨道内的节点可通过对称操作相互转换。轨道数量越少，说明节点之间的对称性等价关系越多。 |
| 稳定子（Stabilizer） | 自同构群中使某个着色方案保持不变的置换子集的大小。稳定子越大，该着色方案的对称性越高、在群作用下的重复拷贝越少。 |
| CIF（晶体学信息文件） | Crystallographic Information File，国际晶体学联合会制定的标准格式，用于存储晶体结构的晶胞参数、原子坐标、空间群、键连关系等信息。是材料科学领域通用的结构数据交换格式。 |
| Burnside引理 | 群论中的计数定理，本系统利用它进行枚举完整性的自验证：所有轨道代表元的稳定子倒数之和应等于恒等置换的不动点数除以群阶。 |
| 着色方案（Coloring） | 将不同类型配体分配到拓扑图中各节点的一种方案。系统需找出所有对称性不等价的着色方案，每种方案对应一个可能的 MOF 结构。 |
